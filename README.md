# 🧸 Chibi Avatar Maker

自分だけの2頭身アバターを作って、cluster にアップロードできる VRM 1.0 形式で書き出せる Web アプリです。3D の知識がなくても、パーツを選んでいくだけで数分でオリジナルアバターが完成します。

## 必要環境

- Node.js 20 以上（開発は Node.js 22 で確認）
- npm 10 以上
- モダンブラウザ（Chrome / Edge 推奨。WebGL2 対応が必要）

## インストール方法

```bash
npm install
```

## 起動方法

```bash
npm run dev
```

表示された URL（デフォルトは http://localhost:5173 ）をブラウザで開いてください。

## Build 方法

```bash
npm run build     # 型チェック + 本番ビルド (dist/ に出力)
npm run preview   # ビルド結果をローカルで確認
npm run lint       # ESLint
```

## フォルダ構成

```
src/
├── components/     # UI コンポーネント (React)
├── avatar/         # 3Dアバター構築ロジック（骨格・パーツ合成・アニメーション）
├── vrm/            # VRM 1.0 書き出し・検証
├── store/          # Zustand ストア（アプリの状態管理）
├── types/          # TypeScript 型定義
├── data/           # パーツ/プリセット/cluster制限値の JSON データ
└── utils/          # ダウンロード・スクリーンショット・localStorage 保存
public/
└── assets/avatar/  # 3D アセット（GLB）置き場
```

## アセットについて

ベースボディは3段階のフォールバック方式で読み込まれ、どの段階でもアプリがアセット待ちでブロックされることはありません（未読み込みの間は自動的により簡易な下位ティアで仮表示され、読み込み完了後にシームレスに切り替わります）。

1. **リッチボディ（最優先）** — `public/assets/avatar/body/chibi_rich_body.glb`。単一メッシュでテクスチャに顔（目・眉・口・頬）が焼き込まれた高品質アセット（`src/avatar/RichBodyModel.ts`）。`hips` ボーンに剛体として1つだけアタッチされるため、肘・膝で曲がりません — 手を振る/ダンス/歩くの各アニメーションは腕・脚の見た目には反映されませんが、アイドル時の呼吸バウンドなど全身の動きは適用されます。読み込み時は目・口・眉・頬のプリミティブは（顔が二重にならないよう）スキップされます。
2. **分割ボディ（次点）** — `public/assets/avatar/body/chibi_base_2head_tpose.glb`。頭・首・胴・腰・腕・脚がパーツごとに分かれたジオメトリのみのアセット（`src/avatar/ChibiBaseBody.ts`）で、`src/avatar/HumanoidRig.ts` の人型ボーンにそれぞれリグ付けされ、ボーンの回転で正しく曲がります。
3. **プロシージャルプリミティブ（最終フォールバック）** — 上記どちらも読み込めない場合に使われる、球・カプセル・ボックスなどの簡易形状（`buildLimbs`/`buildNeck` など）。

髪・目・口・服・靴・アクセサリー・背中アイテムは、まだ専用の GLB が用意できていないため、**プロシージャルなプリミティブ形状**（球・カプセル・ボックスなど）で表現しています。`src/data/parts.json` の各パーツ定義に `model` フィールド（GLB へのパス）を追加するだけで、`AvatarLoader.ts` / `AvatarBuilder.ts` が自動的にそちらを優先して読み込むように設計されているため、実アセットが揃い次第、コードを変更せずに差し替え可能です。

## パーツの追加方法

1. GLB ファイルを `public/assets/avatar/<category>/` に配置する
2. `src/data/parts.json` の該当カテゴリに新しいエントリを追加し、`model` にパスを指定する

```jsonc
{
  "id": "hair_11",
  "name": "New Style",
  "nameJa": "新しいヘアスタイル",
  "category": "hair",
  "model": "/assets/avatar/hair/hair_11.glb",
  "primitive": [ /* 実アセット読み込み失敗時のフォールバック形状 */ ],
  "attachTo": "head",
  "defaultColor": "#4a3028",
  "colorable": true,
  "compatible": true,
  "estimatedTriangles": 800
}
```

これだけで、パーツ選択 UI に自動的に表示されます（コードの変更は不要です）。

## VRM Export 方法

1. 右パネル「📦 VRM出力・書き出し」でアバター名・作者・連絡先・ライセンスを入力
2. 「VRMを書き出す」ボタンをクリック
3. 書き出し前に自動検証（人型ボーンの過不足、パーツの有無など）が行われ、問題があればエラー内容が表示されます
4. 成功すると `ChibiAvatar_YYYYMMDD_HHmm.vrm` としてダウンロードされます

書き出しは three.js の `GLTFExporter` で標準の `.glb` を生成したあと、その JSON チャンクに VRM 1.0 の `VRMC_vrm` 拡張（Humanoid ボーンマッピング・メタ情報・表情プリセット）を追加してバイナリを再構成する方式です（`src/vrm/VRMExporter.ts`）。出力ファイルは `@pixiv/three-vrm` で正しく再読み込みできることを確認済みです。

> **現状の制限**: パーツがプロシージャル形状のため、表情はモーフターゲットではなく簡易的な形状変化で表現しています。書き出される VRM にも表情プリセット自体は含まれますが、モーフ紐付けは空です。同様に、髪・マント等のスプリングボーン（物理揺れ）も未設定です。実アセット（モーフターゲット付き GLB）に差し替えることで、これらは自然に有効化されます。

## cluster へのアップロード方法

1. 書き出した `.vrm` ファイルを保存する
2. cluster のアバターアップロード画面から、書き出した VRM ファイルをアップロードする
3. アップロード前に、アプリ内の「cluster 対応チェック」パネルで GOOD / WARNING / ERROR を確認しておくと安心です

cluster 側の最新のアップロード要件（ポリゴン数上限・マテリアル数上限など）は `src/data/clusterLimits.json` に集約されています。仕様が変わった場合は、このファイルの数値を更新するだけでアプリ全体のチェック内容に反映されます。
